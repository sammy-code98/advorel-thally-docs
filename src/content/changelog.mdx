## v0.2.0, August 31, 2026

This release turns the DX Guide into a broader, community-based Developer Relations knowledge base.

- Expanded career, advocacy, Developer Experience, community, measurement, reporting, and case-study guidance.
- Added practical examples from Advorel contributors, DXMentorship, and Mojo Africa.
- Added contributor profiles, verified professional links, event photographs, and Joy Ndukwe's Zencoder walkthrough.
- Added official product logos and links to the tools discussed in the guide.
- Introduced the DX Guide logo and matching favicon for light and dark themes.
- Updated the site typography to JetBrains Mono.
- Improved navigation, page descriptions, supported icons, related-page links, and contribution instructions.
- Removed duplicated introductions, repeated content, emoji, em dashes, and en dashes from published pages.

## v0.1.0

The first published version of this documentation.

- A task-focused introduction and quickstart
- Browsable API documentation generated from `openapi.yaml`
